# 📚 Bookinistic Studio

Профессиональное локальное веб-приложение для полуавтоматической пакетной каталогизации букинистических и антикварных книг для маркетплейса **Ozon** с интеграцией нейросети **Gemini Vision AI**, облачного хранилища **Yandex S3 CDN** и локальной базы данных **SQLite**.

---

## 🚀 Быстрый старт

### 1. Требования
- Python 3.9+
- Установленные зависимости:
```bash
pip install -r requirements.txt
```

### 2. Настройка ключей доступа
1. **Google Gemini Vision AI**:
   - Скопируйте `.gemini_api_key.example` в `.gemini_api_key`
   - Вставьте ваш API-ключ Gemini (или укажите переменную окружения `GEMINI_API_KEY`)
2. **Yandex Object Storage (S3 CDN)** *(опционально для прямых ссылок Ozon)*:
   - Скопируйте `.yandex_s3_credentials.example` в `.yandex_s3_credentials`
   - Заполните `bucket`, `key_id`, `secret_key`

### 3. Запуск приложения

```bash
# Через скрипт запуска (macOS / Linux)
./run.sh

# Либо через ярлык двойного клика на macOS:
# start.command

# Либо напрямую:
python3 app.py
```

После запуска откройте в браузере:
👉 **http://localhost:8095**

## 🌟 Ключевой функционал

1. **📱 Беспроводная загрузка фото со смартфона:**
   - Нажмите **«📱 QR для телефона»** в правом верхнем углу интерфейса.
   - Отсканируйте QR-код камерой телефона — откроется защищенная мобильная веб-форма (работает через Cloudflare Quick Tunnel даже через мобильную сеть/VPN).
   - Выберите 20–50 фотографий из галереи — они автоматически ужмутся до оптимального разрешения и мгновенно попадут в единый пул на компьютере.

2. **⌨️ Быстрая раскладка по слотам (хоткеи `1`–`5`):**
   - Все отснятые кадры отображаются в единой горизонтальной ленте.
   - Нажимайте цифровые клавиши для распределения активного фото:
     - **`1`** — 🌟 Главная передняя обложка (строго 1 фото)
     - **`2`** — 🔄 Задняя обложка (штрихкод / цена СССР)
     - **`3`** — 📄 Титульные листы, оглавление и аннотация (мульти-фото, анализируются Vision AI)
     - **`4`** — 🎨 Иллюстрации и развороты (мульти-фото)
     - **`5`** — 📜 Колофон, выпускные данные, дефекты и сохранность (мульти-фото)
   - Фокус моментально и бесшовно переходит к следующему неразобранному кадру.

3. **🤖 Интеллектуальный каскад Gemini Vision AI:**
   - Отказоустойчивый пул моделей: `gemini-3.5-flash-lite` → `gemini-flash-lite-latest` → `gemini-3-flash-preview` → `gemini-3.5-flash`.
   - Автоматически распознает:
     - Название, авторов, издательство, год издания, страницы, тип бумаги, оформление обложки.
     - Корректные ФИО автора: «Автор на обложке» (по стандарту книги) и «Автор (ФИО)» (официальный паспортный реестр Ozon).
     - Официальный номер формата издания по ГОСТ (например, `70х100/16`, `84х108/32`, `60х90/16`).
   - **Физический расчет габаритов и веса**: на основе формата листа, количества страниц и плотности бумаги вычисляет физическую толщину корешка, габариты и чистый вес книги с точностью < 2%, а затем автоматически начисляет логистическую упаковку Ozon (ОВХ).

4. **☁️ Yandex Object Storage (S3 CDN) + Cloudflare Fallback:**
   - Загруженные фотографии книги пакетом выгружаются в публичный S3-бакет Yandex Cloud с кэшированием `Cache-Control: public, max-age=86400` и мгновенными прямыми ссылками для Ozon.
   - В случае отсутствия конфигурации S3 автоматически активируется локальный защищенный туннель Cloudflare.
   - Встроенный кадрировщик фото (Cropper.js) и нейросетевое отбеливание/удаление фона (rembg).

5. **🗄️ Локальная база данных каталога (SQLite):**
   - Все заполненные карточки сохраняются в локальную базу `storage/catalog.db` с гибридной архитектурой: индексируемые поля (`article` PK, `title`, `author`, `year`, `price`, `template_mode`, `status`) + полный снимок атрибутов в JSON.
   - Автоматическая сквозная нумерация артикулов (проверяет как базу, так и локальный архив `storage/books_vault`).

6. **📊 Генерация таблиц Ozon OpenXML:**
   - Поддержка двух регламентных шаблонов Ozon:
     - **Книги после 2011 года** (86 колонок, штрихкоды EAN-13, ISBN).
     - **Книги до 2011 года (Букинистика)** (специальные поля сохранности, статус «генерирует озон»).
   - Прямая генерация через потоковый OpenXML (`zipfile` + `xml.etree.ElementTree`) без внешних тяжелых зависимостей.
   - Встроенная таблица предварительного просмотра с возможностью удаления строк и автоматическим созданием резервных копий (`ready_tables/backups/`).

## 📁 Структура проекта

```
bookinistic/
├── app.py                             # Точка входа HTTP-сервера
├── config.py                          # Глобальные пути, порт, конфигурации S3/AI
├── run.sh                             # Скрипт быстрого запуска в терминале
├── start.command                      # Двойной клик для запуска на macOS
├── requirements.txt                   # Зависимости Python (Pillow, boto3, rembg)
├── core/                              # Бизнес-правила, справочники и генераторы штрихкодов
│   ├── barcode.py                     # EAN-13 калькулятор контрольной суммы
│   └── constants.py                   # Системные промпты и категории Ozon
├── services/                          # Модули бизнес-логики и интеграций
│   ├── ai_service.py                  # Взаимодействие с Google Gemini Vision
│   ├── enrichment_service.py          # Расчет физических параметров книги (ГОСТ)
│   ├── s3_service.py                  # Загрузка фото в Yandex Object Storage (S3 CDN)
│   ├── excel_service.py               # Генерация и редактирование Ozon OpenXML
│   ├── db_service.py                  # Каталог SQLite и сквозные артикулы
│   ├── vault_service.py               # Локальный защищенный архив фото книг
│   ├── image_service.py               # AI обработка изображений (rembg, Pillow)
│   └── tunnel_service.py              # Cloudflare Quick Tunnel
├── server/                            # Веб-сервер и обработчики REST API
│   ├── handler.py                     # Маршрутизация REST API и статических файлов
│   └── state.py                       # Менеджер событий беспроводной загрузки
├── templates/                         # Шаблоны Ozon и интерфейсы
│   ├── desktop.html                   # Основной рабочий стол каталогизатора
│   ├── mobile.html                    # Мобильная форма быстрой загрузки фото
│   ├── Печатная книга_template.xlsx           # Шаблон Ozon (после 2011)
│   ├── Печатная книга_до_2011_template.xlsx   # Шаблон Ozon (до 2011)
│   └── card.png                       # Фирменная инфо-карточка для Ozon
├── storage/                           # Рабочие данные (не отслеживаются в Git)
│   ├── inbox/                         # Буфер свежих фото со смартфона
│   └── books_vault/                   # Локальный архив отснятых книг по артикулам
├── ready_tables/                      # Готовые сформированные таблицы для Ozon
│   ├── 1942-2010/                     # Книги 1942–2010 гг. (шаблон 81 колонка A..CC)
│   ├── с_2011/                        # Книги с 2011 г. (шаблон 86 колонок A..CH)
│   └── backups/                       # Автоматические резервные копии таблиц по эпохам
├── PHOTO_PIPELINE.md                  # Регламент и алгоритм обработки фотографий
├── BARCODE_CHEAT_SHEET.md             # Справочник по штрихкодам и этикеткам
└── TECH_STACK.md                      # Детальное архитектурное описание
```
