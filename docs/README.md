# 📚 База знаний и памятки Bookinistic Studio

Добро пожаловать в единый центр документации студии каталогизации букинистических книг для маркетплейса **Ozon**.

Здесь собраны все регламенты, стандарты полей, справочники допустимых значений, инструкции по фотосъемке и безопасности.

## 📖 Подробное описание памяток

### 1. 📋 [OZON_FIELDS_GUIDE.md](file:///Users/igor/Projects/real_projects/bookinistic/docs/OZON_FIELDS_GUIDE.md)
*Главный стандарт каталогизации книг для Ozon*
- **Для кого**: Операторы-каталогизаторы, контент-менеджеры, разработчики.
- **Содержание**:
  - Сводная таблица всех полей для шаблонов **до 2011 г. (81 колонка A..CC)** и **после 2011 г. (86 колонок A..CH)**.
  - **Обязательный ручной ввод цены** букинистом (ИИ оставляет цену строго пустой).
  - Строгие правила по **12 типам бумаги** (выбор только при 100% подтверждении в колофоне).
  - Разделение «Автор на обложке» vs «Официальный автор» (сверка с базой 1,310 авторов).
  - Расчет габаритов упаковки и веса по ГОСТам (доля листа, мантра, плотность картона).
  - Папки сохранения готовых таблиц (`ready_tables/1942-2010/` и `ready_tables/с_2011/`).

### 2. 📖 [OZON_DICTIONARIES.md](file:///Users/igor/Projects/real_projects/bookinistic/docs/OZON_DICTIONARIES.md)
*Официальные словари допустимых значений Ozon*
- **Для кого**: Каталогизаторы, проверяющие соответствие карточки Ozon.
- **Содержание**:
  - **16 типов обложки и переплёта** (бумвинил, интегральный, ткань, суперобложка и др.).
  - **12 типов бумаги** (типографская, офсетная, газетная, пухлая, мелованная и др.).
  - **56 официальных направлений/жанров** (детектив, проза, фантастика, поэзия и др.).
  - **5 градаций сохранности книги** (от «Удовлетворительной» до «Отличной»).
  - Возрастные маркировки (`0+`, `6+`, `12+`, `16+`, `18+` или пусто).

### 3. 🏷️ [OZON_BRANDS.md](file:///Users/igor/Projects/real_projects/bookinistic/docs/OZON_BRANDS.md)
*Реестр книжных брендов и издательств Ozon*
- **Для кого**: Каталогизаторы при заполнении поля «Бренд».
- **Содержание**:
  - Полный алфавитный реестр **397 подтвержденных брендов Ozon**, извлеченных из базы реальных товаров `storage/catalog.db`.
  - Рейтинг **ТОП-30 самых частых издательств** магазина.
  - **Золотое правило**: если издательства нет в списке утвержденных Ozon $\to$ указывать `Нет бренда`, сохраняя историческое название типографии в поле «Издательство».

### 4. 🔑 [KEYS_GUIDE.md](file:///Users/igor/Projects/real_projects/bookinistic/docs/KEYS_GUIDE.md)
*Справочник по ключам, доступам и переменным окружения*
- **Для кого**: Администраторы системы, разработчики, пользователи при первом запуске.
- **Содержание**:
  - Настройка **Google Gemini API** (бесплатный ключ для ИИ).
  - Настройка **Ozon Seller API** (импорт каталога и проверка товаров).
  - Настройка **Yandex Object Storage** (S3 CDN для фото и бэкапов).
  - Работа без белого IP через **Cloudflare Tunnel**.
  - Приоритеты загрузки: `.env` $\to$ `credentials/` $\to$ корень проекта.

### 5. 📸 [PHOTO_PIPELINE.md](file:///Users/igor/Projects/real_projects/bookinistic/docs/PHOTO_PIPELINE.md)
*Регламент и алгоритм обработки фотографий*
- **Для кого**: Фотографы студии, операторы съемки.
- **Содержание**:
  - Порядок и ракурсы съемки:
    1. Главное фото (лицевая обложка).
    2. Титульный лист (название, автор, год).
    3. Выходные сведения / мантра (тираж, бумага, типография).
    4. Оглавление и развороты с иллюстрациями.
    5. Фиксация дефектов (потертости, надрывы, штампы).
  - Постоянная инфо-карточка студии `card.png` (последний слайд в галерее).
  - Автоматическая обрезка, удаление фона (`rembg`) и отбеливание.

### 6. 🏷️ [BARCODE_CHEAT_SHEET.md](file:///Users/igor/Projects/real_projects/bookinistic/docs/BARCODE_CHEAT_SHEET.md)
*Справочник по штрихкодам, ISBN и термоэтикеткам*
- **Для кого**: Работники склада, упаковщики, каталогизаторы.
- **Содержание**:
  - Преобразование ISBN-10 и ISBN-13 в штрихкод товара.
  - Автоматическая генерация внутреннего штрихкода **EAN-13** по артикулу (префикс `200...` с контрольной суммой GS1).
  - Печать этикеток на термопринтере (размер **58х40 мм**) с названием, артикулом, автором и штрихкодом.

*Техническое описание и архитектура*
