# 🧠 Шаг 2: Интеллектуальное распознавание (Gemini, FantLab, catalog.db)

> **Статус**: ⚪ Запланирован  
> **Цель**: Сокращение времени ответа Gemini в 2–3 раза, точные паспортные данные из FantLab с ручным подтверждением, подбор вариантов по закрытым базам Ozon.

---

## 🎯 Согласованные технические правила

1. **Минимизация токенов и сжатие перед отправкой в Gemini Vision**:
   - В Gemini отправляются строго: лицевая обложка (`cover_front`), титульный лист (`title_page` / `info_pages[0]`), колофон/мантра (`colophon` / `mantra`).
   - Дефекты и иллюстрации в Gemini **не отправляются**.
   - Перед кодированием в base64 кадры масштабируются до максимальной стороны 1200px с качеством JPEG 85% (уменьшение объема запроса на 60–70%).

2. **Раздельный режим обогащения через FantLab**:
   - Поиск по ISBN (если найден штрихкод) или по названию + автору.
   - Данные не перезаписывают форму автоматически вслепую.
   - В интерфейсе появляется заметный бейдж: `«📚 Найдено в FantLab: [Название книги]»`.
   - При клике оператор видит карточку сравнения и подтверждает перенос:
     - Официальные ФИО переводчиков (по стандарту Ozon);
     - Официальные ФИО художников-иллюстраторов;
     - Оригинальное иностранное название (`original_title`);
     - Серия книги;
     - Число страниц и издательская аннотация.

3. **Сверка по закрытой базе Ozon (`catalog.db`)**:
   - Проверка издательства по 397 брендам Ozon (подстановка утвержденного бренда либо «Нет бренда»).
   - Проверка авторов по базе 1 310 канонических авторов магазина.
   - Система предлагает варианты в автодополнении, не подменяя автора/бренд без согласия оператора.
