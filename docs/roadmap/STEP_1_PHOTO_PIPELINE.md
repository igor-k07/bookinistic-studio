# 📸 Шаг 1: Оптимизация фото-конвейера и Фотостудия

> **Статус**: 🟡 Готов к разработке  
> **Цель**: Ускорение обработки фото пачки в 5 раз, защита белых обложек, удобное кадрирование и пресеты.

---

## 🎯 Согласованные технические правила

1. **Селективный `rembg` (удаление фона стола)**:
   - Применяется **автоматически** только для слотов `cover_front` и `cover_back`.
   - **Титульные листы, текст, колофон**: категорически запрещено вырезать фон. Сохраняется естественный разворот книги.
   - **Иллюстрации и дефекты**: по умолчанию сохраняются без вырезания фона; доступно точечное вырезание кнопкой `✨` на карточке или в фотостудии (`force_rembg=True`).

2. **Защита белых и светлых обложек (`services/image_service.py`)**:
   - Автоматический гибридный анализ на базе OpenCV.
   - Если обложка светлая или rembg удаляет площадь внутри переплета, сервер находит внешний контур блока книги и заливает внутреннее пространство 100% непрозрачностью.
   - Отбеливается только внешняя часть кадра (фон стола).

3. **Кадрирование Cropper**:
   - Авто-рамка выставляется по естественному контуру книги с запасом `+3.5%` (свободные пропорции).
   - В фотостудии доступно мгновенное переключение на пропорцию `3:4` (стандарт Ozon) кликом по кнопке.
   - При сохранении книги: если оператор не открывал студию и не кадрировал обложку вручную, автоматически применяется кадрирование по вычисленному контуру `crop_relative` (+3.5%).

4. **Пресеты в Фотостудии**:
   - 📝 **«Четкий текст»**: `contrast: +18, brightness: +3, whiten: 0, saturation: 0`
   - 🎨 **«Яркие иллюстрации»**: `saturation: +15, contrast: +8, whiten: 0, brightness: 0`
   - ⚪ **«Чистый фон»**: `whiten: 75, contrast: +5, brightness: +2, saturation: 0`
   - ↩️ **«Сброс в ноль»**: все параметры в 0

5. **Очистка панели пула**:
   - Удаление избыточной общей кнопки «✨ ИИ-вырезать фон пачке» из панели пула.

6. **Строгий эталонный порядок фото в карточке Ozon**:
   - `1` — `01_cover_front.jpg` (**Лицевая обложка**, главное фото).
   - `2` — `02_defect_<N>.jpg` (**Дефекты книги по порядку**, если есть; первые доп. фото).
   - `3` — `03_illustration_<N>.jpg` (**Иллюстрации и развороты**, если есть; идут перед задником).
   - `4` — `04_cover_back_<N>.jpg` (**Задняя сторона переплета**, в конце перед карточкой).
   - `5` — `99_card.jpg` (**Шаблонная карточка магазина с предупреждением**, финальное доп. фото).
   - 🚫 **Титульные листы и мантра** (`info_page_<N>.jpg`) — сохраняются ТОЛЬКО в архив (`books_vault` и облачный `archive/`), в карточку Ozon **НЕ попадают**.

| Файл | Описание изменений |

| `core/use_cases/process_photo.py` | Ролевой фильтр для `rembg`, поддержка флага `force_rembg`. |
| `core/use_cases/save_book.py` | Автоматическое применение `crop_relative` для обложки при записи книги. |

| `templates/static/pipeline.js` | Авто-запуск обработки при попадании в слоты обложек, удаление пакетного вызова. |
| `templates/static/studio.js` | Реализация логики пресетов, свободная инициализация Cropper, force_rembg из студии. |
