# 🚀 Шаг 5: Интеграция с Ozon Seller API

> **Статус**: ⚪ Запланирован  
> **Цель**: Публикация карточек книг в Ozon в 1 клик через официальный Seller API с валидацией обязательных атрибутов и сохранением резервной копии Excel.

---

## 🎯 Согласованные технические правила

1. **Гибридный сценарий публикации**:
   - **Поштучная выгрузка**: кнопка `«🚀 Записать и отправить в Ozon»` прямо на форме текущей книги.
   - **Пакетная выгрузка**: общая кнопка `«🚀 Опубликовать всю пачку в Ozon (N книг)»` в реестре готовых книг текущей сессии.

2. **Формирование атрибутов под регламент Ozon**:
   - Категория: «Печатные книги» (ID категории Ozon: 17027949).
   - Обязательные атрибуты: артикул (`offer_id = DP-B-XXXXX`), штрихкод (EAN-13), название, автор, издательство/бренд, год, вес и габариты (ГОСТ), ссылки на фото в Yandex S3, аннотация, тип обложки.
   - Отправка через официальный метод `POST /v3/product/import`.

3. **Мониторинг статуса модерации**:
   - При успешном вызове Ozon возвращает `task_id`.
   - Фоновый поллинг `POST /v1/product/import/info`:
     - ⏳ `На модерации Ozon`
     - ✅ `Успешно создан / В продаже`
     - ⚠️ `Ошибка атрибутов Ozon` (с расшифровкой причины, например: «Недопустимый бренд» или «Длина названия превышена»).

4. **Двойная надежность**:
   - Создание локальной таблицы Excel (`ready_tables/<дата>_Печатная книга_*.xlsx`) выполняется параллельно и всегда сохраняется как локальный архив и резервная копия.
